# Crowdsourced Skill Swap Network: Design Documents

Software-engineering documentation (CSE251) for the **Crowdsourced Skill Swap Network**: an online platform where people trade skills instead of money. Users offer something they know (coding, cooking, music, design…) and learn other skills from the community in return.

This repository is documentation only. The implementation lives in [skill-swap-platform](https://github.com/Rewanooo22/skill-swap-platform).
